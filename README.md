# 乾媽家庭銀行 1.0

繁體中文家庭金融教學網站。13 歲姐姐為銀行經理、11 歲弟弟參與儲蓄冒險；爸爸媽媽監督真實零用錢收付。

## 開始使用

1. 打開網站，先按「先探索遊戲展示版」。展示資料不會保存，也不會影響真實帳目。
2. 正式使用時，每人以自己的 Email 與密碼登入或建立會員。可沿用易經系統的 Supabase 會員；不需要 ChatGPT 登入。
3. 爸爸先開設家庭銀行，輸入已實際收到的乾媽紀念基金金額。三戶存款從 0 開始；基金獨立記為銀行資本。
4. 爸爸將家庭邀請碼私下交給媽媽、姐姐、弟弟。三人登入後申請加入，爸爸在「家庭設定」核准並指定角色。
5. 父母設定每戶未來四週確定可用零用錢，再由各戶申請存入已有現金。父母確認實際收付才入帳。

## 四個會員與三個帳戶

- 爸爸、媽媽各有登入身分，共同管理 001。
- 姐姐登入身分管理 002，另有經理工作台；自己的申請不能自己核對。
- 弟弟登入身分管理 003，只能查看自己的帳目與家庭紀念簿。
- 001 交易與所有借款需兩位家長分別確認，不能用同一登入替另一人批准。
- 未核准的加入申請看不到銀行資料；其他家庭的會員看不到本家庭資料。

## 計息與現金

存款年息 0.825%，參考臺灣銀行 2026/10/12 活期儲蓄存款牌告。貸款 6% 為教學假設。按實際天數除以 365，存款每戶每月、貸款全部還清時最後取整元。正數小數 0.5 以上進位，不逐日取整。月末入息從次月開始計息。

現金＋未還貸款本金＝三戶存款負債＋銀行淨資產。原始紀念基金只投入一次；追加款與累計損益分開記錄。借貸每筆最多 200 元、確定可用零用錢 25%、最長 28 天；全行未清本金不超過原始資本 10%，保留全額存戶存款與 10 元利息準備。到期後停息，由父母協助，不罰息或自動扣款。

第一版以現金還本付息為主，不提供存款自動抵扣、借新還舊、刪除已入帳交易或改寫帳目。異常先停止交易，由父母核查與備份。

## 每週怎麼玩

一週約 10 至 20 分鐘：看願望目標、完成一個情境選擇、一起說明理由；週末主持銀行會議並核對現金。徽章只代表學習，不發放現金、不鼓勵借款、不設每日連續登入。

## 部署與維護

網站為靜態 HTML/CSS/ES modules，可部署至 GitHub Pages。`config.js` 只使用公開 Supabase anon/publishable 金鑰；絕不可放 service_role 或私人密碼。銀行資料在 11 張獨立 `fb_` 資料表，沒有修改易經 `user_progress`。

所有讀寫使用 `fb_command` RPC，直接資料表讀寫權限已撤銷並啟用 RLS；函式每次檢查使用者與家庭、家長批准、限額、日期與資產負債式，以家庭資料列鎖序列化入帳。紀念簿文字顯示時轉義。

初始化 SQL 在 `schema.sql`，正式專案安裝一次；不可重跑已成功的安裝。`database-tests.sql` 為交易回滾測試，不留下測試使用者或帳目。另附本地利息與會計驗算測試。

每週家長可匯出銀行帳目 JSON 作紀錄備份；此檔案含家庭金融資料，應私下保存，不能放到公開儲存庫。資料庫完整災難復原備份另由 Supabase 管理端處理。



## 定存與官方利率同步

「我的定存」支援 1、3、6、12 個月；初始牌告為臺灣銀行 2026/10/14 一般固定定期存款年息 1.225%、1.290%、1.465%、1.700%。家長核准當日開立並鎖定利率，後續牌告或人工調整不影響既有定存。存款合計包含可用活期與定存本金；轉存不增加現金、存款負債或銀行資本。

利息採本金 × 鎖定年利率 × 開立至到期實際天數 ÷ 365，到期轉回時最後四捨五入至整元。提前解約按家庭教學規則不付息、歸還全部本金；到期不自動續存，待家長核准轉回期間不追加利息。月末活期計息扣除當日鎖定本金。

家長在「家庭設定」管理四種定存利率與官方同步開關。同步預設關閉；開啟後家長登入當日檢查一次，也可按「立即同步官方牌告」。網站關閉時不會在背景排程。同期新定存使用最新利率，活期利率從次月開始；失敗、過期或不完整牌告不會取代原利率。「檢查官方連線（不改利率）」只讀公開牌告，不開啟同步、不修改帳目。

同步服務 `bank-rate-sync.ts` 部署在 Supabase Edge Functions，保留預設 Verify JWT 驗證。GET 回傳公開牌告；POST 再逐次驗證登入與本家庭父母角色、同步開關，透過同一銀行 RPC 保存。官方来源固定 https://rate.bot.com.tw/twd?Lang=zh-TW ，沒有寄送家庭帳目。

`migration-002-terms.sql` 為已安裝的第二次升級，不可對已升級專案重跑。`term-database-tests.sql` 以交易回滾驗證本金鎖定、角色隔離、到期/提前解約、次月利率、舊牌告拒絕及資產負債平衡，不保留測試資料。
